# LORDS MOBILE ACADEMY — Vision du Projet

## Mission

Créer une **bibliothèque de tutoriels interactifs et amusants** consacrée au jeu Lords Mobile, destinée principalement aux membres d'une guilde.

Le site sera :
- Gratuit et sans publicité
- Pédagogiquement excellent (expérience amusante, dynamique, immersive)
- Facilement éditable (interface visuelle sans code)
- Développé rapidement (solutions gratuites, architecture simple)

## Trois Priorités Absolues

1. **Expérience pédagogique exceptionnelle**
   - Navigation amusante et ludique
   - Interactions régulières avec le contenu
   - Pas de longues pages statiques
   - Animations pertinentes (légères, utiles)
   - Accessibilité mobile excellente

2. **Édition visuelle simple**
   - Aucun contact avec le code nécessaire
   - Interface intuitive pour administrateurs R4
   - Boutons crayon sur chaque contenu
   - Formulaires simples pour ajouter/modifier
   - Publication directe depuis l'interface

3. **Développement raisonnable**
   - Stack simple et éprouvée (React, GitHub Pages)
   - Coûts gratuits
   - Maintenance facile
   - Pas de chantier complexe
   - Déploiement progressif par phases

## Public Cible

- Membres de la guilde (initial)
- Joueurs Lords Mobile sérieux
- Niveau : débutant à avancé
- Appareils : smartphone prioritaire + desktop

## Restrictions Importantes

- ❌ Pas de jeu de simulation complet
- ❌ Pas de compte utilisateur obligatoire
- ❌ Pas de base de données commerciale (Supabase)
- ❌ Pas de vocation commerciale
- ❌ Pas de présentation comme produit officiel IGG

## Autorité et Validation

- Utilisateur final : seul décideur
- Kiro : architecte, développeur, assistant technique
- Spécifications : cahier des charges consolidé

## Gouvernance des Contenus

- **Contenu source** : 8 PowerPoint fournis (analyse complète effectuée)
- **Sources externes** : Wiki, guides IGG (pour enrichissement)
- **Vérification** : Distinguer mécanique/stratégie/pratiques de guilde
- **Intégrité** : Jamais inventer, signaler contradictions
- **Terminologie** : Préserver langage du jeu et de la guilde
